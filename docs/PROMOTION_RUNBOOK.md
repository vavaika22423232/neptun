# Neptun: просування та SEO (runbook)

Короткий робочий документ для команди. Детальний потік даних карти: [`NEPTUN_DATA_FLOW.md`](./NEPTUN_DATA_FLOW.md).

## Google Search Console

1. Додайте властивість `https://neptun.in.ua` (Domain або URL prefix).
2. Верифікація через HTML-тег: у змінній оточення **`GOOGLE_SITE_VERIFICATION`** на сервері (див. `nextjs-app/.env.example`) вкажіть значення з Search Console. Після деплою мета-тег з’явиться з кореневого `layout`.
3. Надішліть / перевірте `sitemap.xml` (генерується з `nextjs-app/src/app/sitemap.ts`).
4. Моніторинг: **Покриття**, **Покращення (Core Web Vitals)**, **Запити** — виправляйте критичні помилки індексації та дубльовані title.

## UTM-мітки

Хелпери: `nextjs-app/src/lib/share-urls.ts` (`withUtm`, `mapHomeUrl`).

| Кампанія (приклад) | Де використано |
|--------------------|----------------|
| `footer_android` / `footer_ios` | Футер сайту |
| `telegram_banner` | Банер Telegram (`TelegramBanner`) |
| `faq_modal` | Модалка FAQ |
| `about_android` / `about_ios` | Сторінка «Про нас» |
| `region_back`, `region_open_map`, `region_steps` | Сторінки `/region/[slug]` → головна карта (`utm_content` = slug області) |
| `city_nav`, `city_open_map`, `city_not_found` | Сторінки `/city/[slug]` → головна карта |

Для постів у Telegram додавайте вручну до посилання на карту:  
`utm_source=telegram&utm_medium=social&utm_campaign=YYYY_MM_DD_post`.

## ASO (Google Play / App Store)

Періодично оновлюйте:

- Короткий і повний опис (ключові фрази: карта тривог, шахеди, Україна — без порівнянь, які не можете обґрунтувати).
- Скріншоти з актуальним UI та підписами українською.
- Поле «Що нового» після кожного помітного релізу.
- Відповіді на відгуки з проблемами.

Посилання на стори вже містять UTM у футері сайту — для крос-посилань з блогу можна копіювати той самий шаблон.

## Партнерства та зовнішні посилання (якісні)

Цільові типи джерел (приклади напрямів, не список «обов’язкових»):

- Регіональні волонтерські та громадські чати (за правилами модерації).
- Освітні та медіа-проєкти, де доречна **сторінка** [`/pro-kartu-dzherela`](../nextjs-app/src/app/pro-kartu-dzherela/page.tsx) як пояснення джерел.
- Локальні радіо/онлайн-медіа — один матеріал з посиланням краще за масовий спам-каталог.

Уникати купівлі «пакетів» посилань — ризик санкцій пошукових систем.

## Контент-календар (мінімум)

- Стаття в блозі на евергрін-тему (інструкція, гайд) — орієнтир щонайменше раз на 1–2 тижні.
- Після великих змін продукту — короткий пост + оновлення відповідної лендінг-сторінки або блогу.

## Сторінка «Джерела й точність»

Публічний URL: **`/pro-kartu-dzherela`** — посилання з футера, SEO-блоку на головній, FAQ, «Про нас».
