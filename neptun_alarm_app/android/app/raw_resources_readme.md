# PRO: Custom alarm sounds

Add these OGG files to `app/src/main/res/raw/` for PRO custom alarm sounds:
- `alarm_sharp.ogg` — "Різкий" option
- `alarm_siren.ogg` — "Сирена" option

Requirements:
- Format: OGG (Android) or MP3
- Keep short (2–5 seconds)
- Lowercase filenames, no spaces (res/raw requires lowercase)

Without these files, PRO users who select custom sounds will get the default system sound.
